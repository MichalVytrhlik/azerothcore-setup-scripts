# azerothcore-setup-scripts

This repository contains shell scripts to build and set up AzerothCore on Ubuntu 26.04 LTS (Resolute Raccoon). Ubuntu 24.04 is no longer supported.

The scripts are organized in the `ubuntu-26.04-lts` folder and target Ubuntu 26.04 LTS only.

Anyone is welcome to review these scripts and share feedback.

Thank you.
